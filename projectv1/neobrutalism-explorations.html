Study-Hub — Neobrutalism explorations

Ten aesthetic directions for the same dashboard components (online row, card grid with flip-on-live, completion log). All ten use the exact same markup/layout — only color, border weight, shadow, and type change — so this is purely a look-and-feel exercise, not a functional build.

Parked: these are visual references only. No backend logic here. Hover any face-down card to preview the flip animation.
